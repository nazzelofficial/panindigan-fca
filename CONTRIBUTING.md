Contributing to Panindigan FCA

Thank you for your interest in contributing to Panindigan FCA! This document provides guidelines and instructions for contributing to the project.

Getting Started

Prerequisites


Node.js 22+
Bun or npm/yarn
Git


Setup


Fork the repository
Clone your fork:


bash   git clone https://github.com/your-username/panindigan-fca.git
   cd panindigan-fca


Install dependencies:


bash   bun install


Create a branch for your feature:


bash   git checkout -b feature/your-feature-name

Development

Running Tests

bashbun run test

Running Coverage

bashbun run test:coverage

Code Style


Use TypeScript for all new code
Follow existing code style and patterns
Add tests for new features
Ensure all tests pass before submitting


Commit Messages

Use clear, descriptive commit messages:


feat: add new feature
fix: resolve issue with X
docs: update documentation
test: add tests for Y


Pull Request Process


Ensure your code follows the project's style guidelines
Write tests for your changes
Run tests and ensure they pass
Update documentation if needed
Submit a pull request with a clear description of your changes


PR Checklist


 Tests pass
 Coverage thresholds are met
 Documentation is updated
 Commit messages follow conventions
 No merge conflicts
